① 产生数据

应用程序生成原始数据

浏览器发起 HTTP 请求 / FTP 上传文件 / SSH 远程登录 / DNS 查询域名 / DHCP 申请地址

数据 Data

应用层 Application 报文 / 数据 Data

为应用程序提供网络服务接口，负责产生与解析用户数据，是用户与网络交互的入口。

协议
HTTP / HTTPSDNS FTPSMTP DHCPTelnetSSH
设备
应用网关 / 代理服务器终端主机
⑤ 交付数据

交给对应应用程序

按目的端口号分用（如 80→Web 服务、21→FTP），应用进程收到原始数据并展示/处理

数据 Data
② 加传输头

添加 TCP / UDP 头部

写上源端口、目的端口；TCP 还做三次握手、分段、确认与重传

TCP头 | 数据 → 段 Segment

传输层 Transport 段 Segment

端到端（进程到进程）的传输：用「端口号」标识应用进程，提供可靠或不可靠两种服务。

协议
TCP（面向连接 · 可靠 · 三次握手） UDP（无连接 · 低开销）
设备
主机协议栈（四层）防火墙
④ 去传输头

剥离 TCP / UDP 头部

校验序号与确认号，TCP 按序重组分段、回送 ACK，向上交还原始数据

段 → 数据
③ 加 IP 头

添加 IP 头部

写上源 IP、目的 IP 与 TTL；查路由表决定下一跳（网关）

IP头 | 段 → 包 Packet

网络层 Network 包 Packet

逻辑编址与路径选择：跨网络把包从源主机路由到目的主机（路由器逐跳转发）。

协议
IPv4 / IPv6ICMP / ICMPv6 OSPF静态路由ARP
设备
路由器 Router三层交换机
③ 去IP头

剥离 IP 头部

核对目的 IP 是否为本机，检查 TTL 与头部校验和，根据协议号上交（6=TCP / 17=UDP）

包 → 段
④ 加帧头帧尾

添加以太网帧头 + FCS

写上源 MAC、目的 MAC（ARP 解析所得），帧尾附 FCS 循环冗余校验

帧头|包|FCS → 帧 Frame

数据链路层 Data Link 帧 Frame

相邻节点间的可靠传输：MAC 寻址、组帧、差错检测（FCS）、介质访问控制。

协议
Ethernet / 802.3VLAN · 802.1Q STP 生成树LACP 链路聚合PPP
设备
交换机 Switch网桥 Bridge网卡 NIC
② 去帧头帧尾

剥离以太网帧头尾

交换机按 MAC 表转发；网卡用 FCS 校验帧完整性，帧类型字段上交（0800=IP）

帧 → 包
⑤ 变比特流

帧转为电 / 光信号

网卡把比特编码后在传输介质上发送出去

比特流 Bit Stream

物理层 Physical 比特 Bit

在传输介质上透明传输比特流：规定电压、光信号、接口形状与速率等电气/物理特性。

标准
RJ45 / 双绞线光纤 802.11（WLAN 无线）1000BASE-T 等
设备
集线器 Hub中继器 Repeater传输介质
① 收比特流

信号还原为比特

接收网卡把电/光信号解码成比特流，重建出完整的帧

比特流 → 帧
物理传输介质网线 / 光纤 / 无线电波（802.11）
01101…01比特流跨网络传输

FCS校验

发送方每经过一层就加一个头部（封装）；接收方每经过一层就剥掉一个头部（解封装）。 数据链路层同时加「帧头 + 帧尾（FCS）」。播放动画可对照观看每一步。
