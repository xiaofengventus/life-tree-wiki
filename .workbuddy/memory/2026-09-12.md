**T000021 结构（以后可直接引用）**：根 `LUCA露卡` → 3 个一级分支
（原核 215 叶/深 18、病毒 27 叶/深 7、**真核 1215 叶/深 107**，占 83% 叶子、77% 节点）。
最深 107 层，最长单链只有 4。

**算法（`layout3d.js`，纯函数，不依赖 three）**：
1. 半径几何增长 `r(d) = base × K^d` —— 自相似充要条件；
2. 方向在锥内按**球冠面积**均匀铺开 + 黄金角错开；
3. 锥角按**等立体角** `cos αᵢ = 1 − wᵢ(1 − cos αp)`（Σ 子立体角 = 父立体角）；
4. **用「根锥余量」约束**：`βmax = rootSpread − angle(dir,根轴) − αᵢ`；
5. 子节点按**叶子数降序**排（方向按序号铺开，谁靠前谁靠近锥轴，让最大分支居中）。

**踩的两个坑（关键教训）**：
- 先用**父锥**约束（`β ≤ spread − α`）→ 最大分支吃光父锥余量（真核锥角 80°），其余分支被压到轴上 → **"树上部一大坨堆在顶上"**。
- 改成"铺满父锥 + 事后投影回锥面" → 制造了**锥面吸引子**，枝条被投影后沿锥面滑行 → **深层节点全贴着海面走**。
- 最终用根锥余量 → 空间永远够用，两个毛病同时消失。

**`depthExponent`（面板叫「自相似度」）**：`r(d) = base × K^(d^p)`。
`p=1` 严格几何，107 层树最外层半径是根部 **3770 倍**，看全树糊成一团；
**默认 0.85** 把跨度压到 ~49 倍，层次可见。越深的树越需要这个旋钮。

**泛化（用户特别强调"一定要泛化，不要只针对一棵"）**：
- `normalizeTree()` 统一任意输入：`{data:{uid,text}}` / `{label}` / `{name}` / 裸节点 / 缺 uid（按路径补，可复现）/ `children` 非数组 / 成环（WeakSet 切）/ 超大（nodeLimit 兜底）。
- 页面支持下拉切 16 棵树 + **直接拖 json 进来**。

**验证**：`node --test experiments/fractal-3d/layout3d.test.mjs` **26 个全过**（含用全部 16 棵真实树的泛化冒烟）。
性能：2363 节点 = 2 个 draw call（`InstancedMesh` + `LineSegments`），布局 ~10ms。
headless 截图 FPS 低是 SwiftShader 软渲，真机 GPU 不受影响。
